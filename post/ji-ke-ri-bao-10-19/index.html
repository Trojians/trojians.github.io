极客日报 · 10月19日：AI用一年，报错都不想看了

2026-10-19 • 约 5 分钟 • 极客日报 · 阅读 次

今天最扎心的一条，是烧饼社区一位后端程序员的自白：用 AI 写代码快一年，报错已经不想自己看了。V2EX 这边则在聊拖欠工资和要不要提前还房贷，分享创造区清一色是给 Agent 补工具的新玩意。

1. V2EX 热议

  • 《发现大家对拖欠工资这件事接受度很高》（职场话题 · 99 回复）：楼主入职近四年一直准时发薪，这个月突然说资金周转不过来要拖到月底，去年的年终奖也拖到现在。他不解的是，同事们打趣两句就继续热火朝天干活，自己却已经摆烂、连周报都不想写。短评：工资一拖，信任先走，热闹的会议室未必是安心的会议室。原帖
  • 《房贷还有 14w 多，存款有差不多 19w，要不要提前还掉房贷》（问与答 · 94 回复）：楼主是位大龄女程序员，工作目前稳定，但担心哪天突然失业、被迫转行，收入不确定，所以纠结要不要把房贷一次清掉。短评：这笔账算的不是利息，是失业焦虑下的安全感要留多少现金。原帖
  • 《大家的 giffgaff 还能用吗》（程序员 · 61 回复）：楼主一直没收到邮件，前两天还收到短信提醒消费保活，担心这张卡还能活多久；卡上绑了不少账号，暂时又没找到其他卡可以迁移。短评：绑号越多的卡越不敢轻易换，保活提醒一来就得先盘一遍迁移清单。原帖

2. 分享创造 · 新玩意

  • 《做了一个血缘分析平台，解决 Agent 在开发过程中数据库变更造成的跨服务影响的问题》（分享创造）：作者说，Agent 把交付速度抬上去后，数据库变更的风险也变大了——数据流穿过多套数据库、视图和报表时，一次改动会波及哪些跨服务语句很难看清。这个平台通过 MCP 提供字段级血缘检索，让 Agent 改库前先感知下游影响。短评：让 Agent 写得快不难，难的是改之前知道会炸到谁。原帖
  • 《dtool v0.3.0 发布：面向 AI 的数据工作流，从 Excel 起步》（分享创造）：dtool 是一款给 AI Agent 用的本地 Excel 数据流水线 CLI，单二进制、零依赖、无云端、无遥测，仓库开源。作者直指拿 AI 处理表格的痛点：AI 会编数字，结果对不上时不知道哪一步算错。短评：把流程钉成本地可复现的流水线，比反复提示 AI 算仔细点靠谱。原帖
  • 《koto：一句话完成不同 Agent Harness 之间会话复制 / 迁移 / 同步》（分享创造）：想换一个新的 Agent 工具，旧会话迁不过去、上下文要重讲一遍，是不少人的烦恼。koto 用一句 CLI 命令把会话复制到任意 Agent Harness，打破不同框架之间的壁垒。短评：工具换得越来越勤，会话资产反而成了最舍不得丢的东西。原帖

3. NodeSeek × 烧饼社区

  • 《VPS 被黑后沦为 VNC 扫描 / 爆破节点：一次排查记录及自查方法》（NodeSeek）：光看标题就够警醒——自己的 VPS 被黑后，被拿去当 VNC 扫描和爆破的跳板，作者把排查记录和自查方法一并贴了出来。短评：机器闲置不等于安全，长期不看的 VPS 最容易在不知情时变成别人的工具。原帖
  • 《iLatency 公测，一个新的社区内 Ping 站，邀你共建》（NodeSeek）：社区里新开了一个 Ping 站项目 iLatency，正在公测并邀人共建。短评：这类小而专的自建工具，正是社区最有生命力的部分。原帖
  • 《AI 用多了之后，你有没有感觉自己某些基本能力在变差？》（烧饼社区 · 78 条评论）：楼主是 C# 后端，用 AI 写代码快一年，如今回头发现：异常堆栈不想看了，整段复制给 AI；复杂 SQL 和 EF Core 查询说不清翻成的 SQL 长什么样、有没有 N+1；从零写类和接口，脑子里先冒出来的是让 AI 给骨架。短评：效率是真的，退化也是真的，区别只在于还留不留一点自己看堆栈的习惯。原帖

4. 海外极客圈 · Hacker News

  • 《Someone behind the software》（Hacker News · 425 分）：今天 HN 榜首是一篇谈软件背后之人的文章，热度压过一众技术帖。短评：当工具越来越自动，读者反而最想听听做软件的人怎么想。原帖
  • 《Hybrid Reasoning Agents: LLM agents that think in latent space, act through text》（Hacker News · 369 分）：这篇 arXiv 论文提出混合推理 Agent——在隐空间里思考、通过文本行动，把大模型 Agent 的推理方式拆成了两层。短评：Agent 的竞争已经从会不会调用工具，进到怎么思考本身了。原帖
工具越强，越要留一点笨功夫：堆栈自己看一眼，账自己算一遍，别等能力退没了才发现。
