极客日报 · 10月27日：33岁的空当接龙还能在Win11上跑

2026-10-27 • 约 5 分钟 • 极客日报 · 阅读 次

今天的极客圈有点怀旧：1993 年的扫雷在 Win11 上照跑不误，一千年后的人类则在研究我们的外卖盒。中间还夹着节点集体阵亡、Vibe Coding 上线工厂 ERP，以及一台被用户自己维护着的 iPhone Duo。

一、V2EX 热议

  • 《坠机日，大妈和瓦工 3 台机器都阵亡了》（Claude · 112 回复）——楼主下午正用 Claude 干活，突然会话弹出 Server error，第一反应是被封号了，结果一看节点全红，只剩一个冷门机房的节点还活着，其他端口全被封了。短评：工具越顺手，断线那一刻越像断电。原帖
  • 《AI vibe coding 的进展，不知道程序员还能存活多久？》（职场话题 · 87 回复）——楼主那位开劳斯莱斯的朋友，7 月还是 coding 白痴，靠几个月 vibe coding，居然上线了一套能当生产力用的工厂 ERP，按他的说法和业务贴合得简直完美。短评：门槛被拆掉之后，把需求讲清楚的能力反而更值钱了。原帖
  • 《iPhone Duo 有感》（iPhone · 109 回复）——楼主直言这是苹果有史以来最不负责任的一代机器，已经这样了，依旧是一群用户在维护它；他自己早期手机电脑平板手表全套苹果，如今只剩电脑是苹果，下一代连电脑也不打算买了。短评：品牌忠诚度这东西，耗起来比电池快得多。原帖

二、分享创造 · 新玩意

  • 《做了一个自用的个人工作台「脉络」：把安排、执行和总结放在一起，支持 Docker 自部署》（分享创造 · 0 回复）——作者嫌待办工具只记事不跟事，于是做了「脉络 Mailuo」：工作台集中看今日待办和逾期事项，复杂的事拆成阶段和子任务，还能记录要等的人和下次跟进时间，最后按周期回顾时间分布、写总结。目前是社区测试版 0.1.0-beta.1，可 Docker Compose 部署，数据存在本地。短评：待办清单的终点不是记下来，是跟到底。原帖
  • 《多 Agent 协作工作台 Rovai 0.5 更新：团队管理、执行中插话、多 Provider 配置》（分享创造 · 0 回复）——开源多 Agent 工作台 Rovai 迎来 0.5 版，可以把 Claude Code、Codex、OpenCode、Pi 等编程 Agent 组织成长期队友，在同一会话里讨论、分工和交接；新版加了 Team 管理，能给开发组、研究组各定一套协作规矩，还能在执行中插话、多 Provider 切换。短评：Agent 从单兵走向班组，管理工具也得跟上。原帖
  • 《做了个「未来考古局」：一千年后的考古学家怎么研究我们的外卖盒》（分享创造 · 0 回复）——设定在公元 3026 年，考古学家挖到一批 2020 年代的日用品，然后一本正经地写展签：外卖盒被鉴定为「封印供奉盒」，袋口死结是封印，开封前拍照是必要仪轨；键盘是「四方占卜盘」，WASD 四枚磨损最重，推测对应四方神。四个展厅五十件展品，环形展厅可以拖着转，手机也能看。短评：最狠的科幻，是把现在当文物看。原帖

三、烧饼社区

  • 《自建 Cloudflare Tunnel 完整指南：无公网 IP 也能让外网连进来》（烧饼社区）——针对家宽没有公网 IP、服务器 IP 被墙、机房只给内网这几种常见困境，楼主写了一份在 Debian/Ubuntu 上验证过的完整指南：本机跑 cloudflared 向 Cloudflare 边缘建一条 QUIC 长连接，公网请求经 CF 回传到本机，不用开入站端口，还自带 TLS 证书；代理部分用 Xray + VLESS-WS，客户端用 Clash。短评：没有公网 IP 不是死路，只是要多绕一道隧道。原帖

四、海外极客圈 · Hacker News

  • 《The Exponential Time Hypothesis Is False》（Hacker News · 576 分）——OpenAI 放出的一篇预印本论文，宣称证伪了计算复杂性理论里的指数时间假说（ETH），即 3-SAT 这类问题不存在亚指数时间算法的经典假设；论文 10 月 25 日挂出，当天就冲上 HN 热榜前列。短评：要是证明站得住，教科书里的一章就得重写了。原帖
  • 《Oldest GUI application that still runs on Windows 11》（Hacker News · 391 分）——作者较真了一个无聊又迷人的问题：不改不动、不靠模拟，能在 Win11 上跑的最老图形界面程序是哪一个？答案是 1993 年 2 月 22 日的 FREECELL.EXE，也就是扫雷同期的空当接龙，距今 33 年 8 个月，在最新版 Win11 上原样运行、完全可玩。短评：Windows 的向后兼容，有时候比新功能更值得尊敬。原帖

五、Telegram · 极客分享精选

  • 《今天有一大批网友要失联了……》（极客分享 · 2.86K 浏览）——频道 24 小时内最火的一条就是这句没头没尾的感叹，全文就这一行，配上几个笑哭表情，却拿下了 2.86K 浏览。短评：有时候一句话的梗，比长篇大论传得更远。原帖
  • 《Android Ad Cleaner - 一款开源的国产安卓手机去广告工具》（极客分享 · 1.75K 浏览）——用来关掉国产手机系统里的广告、热搜、资讯推荐和营销推送，支持 Windows、macOS 桌面客户端，手机开 USB 调试按提示操作即可，不需要 Root 或刷机。短评：去广告工具的尽头，是把手机还给机主。原帖
今天的共识大概是：旧东西未必过时，新工具也未必省心，能跑 33 年的程序和能讲清楚需求的人，都值得多看一眼。
