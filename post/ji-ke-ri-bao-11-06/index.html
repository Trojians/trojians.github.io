极客日报 · 11月6日：超长密码竟能登入 OpenSSH，十年老洞曝光

2026-11-06 • 约 7 分钟 • 极客日报 · 阅读 次

今天的极客圈被安全话题刷屏：一个藏了十年的 OpenSSH 漏洞、一次 Claude Code 的邮箱泄露，再加上微信输入法的敏感词库被扒了个底朝天，剩下的则是墨水屏阅读器、小游戏复盘这些让人手痒的新玩意。

一、V2EX 热议

  • 《微信输入法敏感词提取器》（信息安全 · 105 回复）：楼主发现微信输入法内置了一个敏感词库，命中该词库的输入无法组词、联想，也形不成记忆，永远不会出现在候选中；而且这个词库并非实时联网获取，而是直接集成在安装包内。在 AI 的辅助下，他写了一个提取器，从安装目录下的 BuildIn\cell_dict.ssrc.zh 文件里把词库扒了出来，词条数量 1 万出头，在 Windows 最新版上测试通过。还有个额外发现：输入法里还藏着一个没那么敏感的词库（kind=440），词能正常组词，却被单独归类，至于有没有特殊处理，楼主还没进一步分析。短评：输入法比你想象的更了解你，本地词库这事，知道总比不知道强。原帖
  • 《无人在意的角落， idea 2026.3 发布了》（JetBrains · 60 回复）：JetBrains IDEA 2026.3 悄悄发布了，楼主一句话总结——这次更新基本都是 AI 方面的功能。短评：IDE 的更新说明越来越像 AI 发布会了。原帖
  • 《如果不上班了，你还能靠什么继续谋生！》（程序员 · 55 回复）：楼主直言很厌恶上班，却又不得已为赚钱硬撑，想问问大家：有没有不上班也能继续谋生的副业？如果不上班了，又能坚持多久？短评：这帖子每年都会火一次，答案年年不一样，焦虑倒是恒定的。原帖
  • 《今天要不要逃命，美股大跌、》（股票 · 61 回复）：美股大跌，楼主只问了一句：今天要不要逃命。短评：标题里的“逃命”二字，就是今天市场情绪的温度计。原帖

二、分享创造 · 新玩意

  • 《用 Claude Code 做微信小游戏的全过程复盘，顺便说下：现在小游戏发布不用先等备案了》（分享创造 · 1 回复）：作者国庆用 Claude Code 搓了个割草小游戏，结果卡在备案上来回改了一个月；现在微信小游戏发布已经不用先等备案了，想做的可以直接冲。复盘干货不少：美术全靠代码一笔一笔画（椭圆、矩形加描边），运行时打包成一张图集，主角奶蛙从像素参考图导入、自动去背景对齐网格；数值方面写了个不渲染画面的模拟器，机器人 1 秒跑完一局，跑了上千局调难度，最后调到首局胜率 22%，每输一次都更强一点；9 个 Boss 各带 4 个技能轮换，所有技能都先给红色预警——被秒杀不好玩，“看见了却没躲开”才好玩。备案曾因截图里的骷髅怪被判“恐怖血腥”驳回，于是全面和谐：骷髅兵变木偶兵、僵尸变泥巴怪、血月变红月，改了好几轮才过。代码已开源。短评：一个不会画画的人，靠 AI 做出了一款能玩的小游戏，备案还顺带松了绑。原帖
  • 《给自己的墨水屏写了个本地阅读器「墨案」： EPUB / 漫画秒开，不联网，开源》（分享创造）：作者用的墨水屏是 Pantone 6 彩墨屏，系统自带阅读器和几个第三方阅读器在 RK3568 这种全小核芯片上都偏慢，开一本书要等三四秒，翻页还有残影，于是自己写了一个，叫墨案。速度是硬指标：冷启动到书架约 0.8 秒，整个过程只刷一次屏；文字书从白屏到出字约 0.6 秒，第二次打开 0.2–0.4 秒；漫画点开到出图约 0.25 秒，每翻一页 CPU 耗时约 85ms；停在一页上时 CPU 几乎为 0，没有后台服务，也没有 WakeLock。排版引擎是自己写的，没用 WebView；全 app 没有动画、渐变和分割线，每个操作都是一帧瞬切。三种阅读模式按书记住：文字用原生排版，原版用 Readium 还原出版商排版，漫画一页一图、支持双指放大；划线有 4 种荧光色，所有书的划线会自动导出成书库根目录下的 Marginalia.txt。短评：为了一块墨水屏从零写个阅读器，这才是极客的浪漫。原帖
  • 《大麦 API 不对个人开发者开放，于是我自己建了一个 10 万场演出的数据库》（分享创造 · 5 回复）：作者是 10 多年经验的 UI/UX 设计师，也是一名演唱会爱好者。市面上的演唱会记录工具要么不好看，要么录入太繁琐，本想接大麦 API，却发现相关接口不对个人开发者开放，干脆自己建数据库：到目前已积累 10 万多场演出记录，涵盖演唱会、音乐节、Livehouse 等类型，还在持续补充。做成的小程序叫「留声档案」：搜歌手就能快速找到对应演出、一键收藏，自带演出海报；能记录每场花费、评分和现场歌单，自动生成个人演唱会海报墙、点亮观演城市足迹地图，还能生成年度观演账单和分享海报。短评：接口不给用，那就自己攒一个库——10 万场，这执行力没谁了。原帖

三、烧饼社区 · 技术交流

  • 《ai漫剧 这个最近挺火的 各位佬有好的开源项目吗》（技术交流 · 6 回复）：楼主开门见山：AI 漫剧最近挺火，想研究相关方案，求推荐好的开源项目，或者有好项目可以分析的发一下链接。帖子还挂了讨论红包征集有价值的回复。短评：AI 漫剧火到有人专门发帖求“抄作业”的路线图了。原帖

四、海外极客圈 · Hacker News

  • 《sshhole》（Hacker News · 2610 分）：musl Linux 上的 OpenSSH（Alpine、OpenWrt、Buildroot、Yocto，以及大量 Docker 镜像）自 2016 年起就藏着一个问题：那些本应永远不能用密码登录的账号——root、仅密钥的部署用户、LDAP 用户、Alpine AWS 与 Azure 镜像的默认用户——输入任意超过 256 个字符的密码就能登录。作者把根源一路追溯到 1980 年：当年 Bill Joy 在 /etc/passwd 里给 daemon 账号打了个 * 标记，表示没人能登录；1990 年代的密码校验、2012 年 crypt 不再返回 NULL、256 字节上限、2016 年的 salt，一环扣一环，最终在今天炸开。短评：一个从 1980 年讲起的故事，结尾是“任意超长密码都能进”，今天安全圈的头条没跑了。原帖
  • 《Claude Code sends your email address to websites》（Hacker News · 979 分）：Anthropic 的 Claude Code 被曝在联网搜索时，把用户的邮箱地址放进了 User-Agent 请求头，发给任意第三方网站。提交 issue 的用户说，自己每天收到几十封诈骗邮件，原因就出在这里；他认为这不该做成可开关的设置，而应从工具里彻底移除，并表示已决定把公司迁移到 Pi 加 OpenRouter。短评：AI 助手替你上网，顺手把你的邮箱也“介绍”给了全世界，这事得有个说法。原帖
今天的极客圈一半是安全警报，一半是动手热情：漏洞提醒你检查自家服务器，墨案和小游戏则提醒你——想做的东西，自己动手就是最快的路。
