极客日报 · 10月16日：买个Claude账号，被骗1198元

2026-10-16 • 约 5 分钟 • 极客日报 · 阅读 次

今天的极客圈，一半在围观一台会「起飞」的跑车，另一半在围观一笔 1198 元的学费：有人买 Claude 账号被骗，帖子被顶上了热榜；海外那边，Meta 研究博客的 Muse Spark Open 登上了榜首。

1. V2EX 热议

  • 《Tesla Roadster 起飞了》（Tesla · 101 回复）：帖子放出发布会视频，称新车零百加速 0.81 秒、用上了火箭技术下放，评论区围着这组数字吵翻了天。短评：参数先放一边，能把「起飞」写进跑车帖标题的，也就这台车了。 原帖
  • 《我买 Claude 账号被骗 1198 的经历》（Claude · 78 回复）：发帖人花 1198 元买所谓的 Claude 5X 独享号，付款前对方承诺「封号可以补」，付款后却先让跑脚本、填第三方 Key；好不容易登录上去，页面显示的只是 Pro，周额度还已经用掉了 27%，退款也没退成。短评：买号这条捷径，尽头往往是这笔学费，帖子值得每个想买号的人先看一遍。 原帖
  • 《谈了三个月的女朋友才发现她和前任有较大经济纠纷》（生活 · 215 回复）：今天回复数最高的一帖。发帖人称，女友先后借出几十万给同事、又借 二十万给前男友，而钱里大部分是银行大额贷款和多平台网贷；更让他膈应的是隐瞒——约好处理这类事要提前沟通，对方还是单独去办了。短评：钱的问题摊开还能商量，信任一旦裂了，才是这帖真正的僵局。 原帖

2. 分享创造 · 新玩意

  • 《被切线路和给朋友远程配 Claude Code 折腾烦了，自己搓了个桌面小工具 Folkbench Switch》（分享创造）：作者混用 Claude Code 和 Codex，手里几家第三方 API 轮着备，一旦哪家 502 就得停下手切换，Codex 切回官方号时 OAuth 登录态还经常丢失、要重新走授权；再加上总被朋友追问怎么配，他干脆用 Tauri 搓了个桌面切换工具。短评：切线路这种重复劳动，正是小工具存在的意义。 原帖
  • 《用 flutter 移植了 vscode，体积只有 15mb，配上 claude code 挺搭的》（分享创造 · 9 回复）：作者把 Monaco 编辑器和 xterm 终端完整移植到 Flutter，做出的 IDE 手感与 VS Code 几乎一致，分发体积只有十几 MB；远程 SSH 时直接用服务器上的 Claude Code，还支持自定义 API。短评：15MB 装下一个能写代码还能跑 AI 的编辑器，这个体积控制有点东西。 原帖
  • 《[送折扣码] V2Echo iOS 版上架了，来听听大家的意见，顺便放 500 个终生会员 5 折名额》（分享创造 · 2 回复）：这款逛 V2EX 的第三方客户端由作者一人开发，iOS 版正式上架 App Store，支持 iPhone 和 iPad；免费用户也能正常阅读、发帖、回复与收藏，这次还放出 500 个终生会员五折名额。短评：一个人把客户端做到上架，靠的正是内测用户一条条反馈磨出来的。 原帖

3. NodeSeek × 烧饼社区

  • 《特斯拉新车有点酷哦，是为了拉 特斯拉和SpaceX股价吗？》（NodeSeek）：仅从标题看，发帖人一边夸新车够酷，一边替特斯拉算起了股价的账。短评：和 V 站那帖放一起看，这台车今天在两个社区的打开方式完全不同。 原帖
  • 《求问，为什么tg最好别用+86手机?》（NodeSeek）：标题本身就是问题——注册 Telegram 时，为什么最好别用 +86 的手机号。短评：手机号和账号绑得越紧，这类隐私顾虑就越常被拿出来问。 原帖
  • 《做了一套智能报价系统后，我想聊聊模型训练与工程落地。》（linux.sb）：一篇多任务模型训练实战长文：一条输入要同时回答多个问题时，让相关任务共享编码器、各自接输出头，比每个问题训一个模型省得多；但作者提醒，先建单任务基线再判断要不要联合，免得负迁移；还要把「提取事实」和「执行决策」分开定义，后者得看订单、权限和业务策略。短评：难得不谈玄学、只谈工程边界的一帖，做业务系统的人值得细读。 原帖

4. 海外极客圈 · Hacker News

  • 《Muse Spark Open》（Hacker News · 778 分 · 392 条评论）：Meta 研究博客的这篇文章今天冲上海外榜首，是 HN 前 30 里分数最高的一条，近四百条评论足见关注度。短评：新东西一出，全球极客先围观再讨论，榜首的位置本身就是一种投票。 原帖
  • 《What I self-host》（Hacker News · 440 分 · 276 条评论）：一篇盘点作者本人自托管服务的清单文章。短评：自托管清单年年有人写、年年有人看——大家想确认的，是自己的数据和服务能不能握在自己手里。 原帖
今天这一桌的暗线是「自己动手」：买号被骗提醒人捷径有代价，而自搓切换工具、自托管服务清单都在说同一件事——极客们最后还是最信握在自己手里的那一份。
