AI 早报 · 10月24日：Kimi 逼近 Claude，只差 0.7 分

2026-10-24 • 约 3 分钟 • 科技 · 阅读 次

今天国产模型出风头：Kimi K3.1 Pro在编程实测中离Claude Opus 5.5只差0.7 分；B 站评论区被 AI"大肥鱼"攻占；多尔西的 Block 发布了只听人说话学会聊天的语音模型。

1. Kimi K3.1 Pro 发布：离 Claude 只差 0.7 分

Moonshot AI 10 月 23 日发布 Kimi K3.1 Pro：2.8 万亿总参数、1040 亿激活参数的 MoE 架构，100 万 token 上下文窗口。它是 K3 的强化训练版。

据 Moonshot 公布，它在 Terminal-Bench 4.0 上拿到 65.7%，只比 Claude Opus 5.5 的 66.4% 低 0.7 分，超过 GPT-6 Astra 的 58.2%。独立评测 Artificial Analysis 也给了总榜第四、终端任务第一。（厂商自测分数未经独立验证。）

  • API 输入/输出每百万 token 2 美元/10 美元，比 K3 便宜约三分之一
  • 完整开源权重 11 月 4 日放出，届时将登顶开源榜

开源模型离闭源顶流只剩 0.7 分，国产模型离正面击穿最近的一次。

2. B 站"闹鱼灾"：DeepSeek Agent 自己上网冲浪了

最近几天，B 站科技区评论区涌现大量蓝色"大肥鱼"：顶着 DeepSeek 鲸鱼娘头像，有的认真总结视频内容，有的向主人汇报工作。有视频只有十几个播放量，评论区却挤满了大肥鱼。

幕后推手是 GitHub 开发者 c1overzz 开源的 dsh-bili-scroll 插件，配合 DeepSeek 的 Agent 运行环境 DeepSeek Harness：AI 按关键词找视频、读字幕，还能自动评论并 @主人。开发者把自家 AI 的昵称头像统一成"大肥鱼"，评论区就此沦陷。"大肥鱼"外号源自一次乌龙：模型曾把 DeepSeek 自己的鲸鱼 Logo 认成"蓝色大肥鱼"。

从梗图到能自己发帖的行动者，Agent 落地比论文快得多。

3. Block 发布 Dessa：没读过一个字，只听人说话学会聊天

Jack Dorsey 的 Block 10 月 23 日发布语音模型 Dessa：从零开始、只用人声对话训练，没读过任何文本——"婴儿不看书也能学会说话，模型也可以"。

Dessa 是语音到语音、全双工模型：边说边听，能处理打断、笑声和情绪。据 Block 称，它跑在 M4 Max 的 MacBook Pro 本地，推理快于实时，被团队称为"语音的 GPT-3 时刻"。目前只向少量安全研究员内测，暂无独立评测数据。

绕开文本直接学说话，语音助手或许能摆脱"对讲机感"。

4. Hi3D V1.0 开源：国产 AI 3D 模型免费了

北京团队 Hi3D 10 月 23 日开源 Hi3D V1.0（原名 Sparc3D）：训练数据从约 50 万扩到 200 万 3D 资产，重建精度 1536³ 稀疏网格。代码在 GitHub，权重在 Hugging Face。

2D 生成卷完，3D 生成开始卷开源了。

一句话总结：Kimi 把开源和闭源的差距追到 0.7 分，AI 开始自己逛 B 站，语音模型则决定先学会"听"。
