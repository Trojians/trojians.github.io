极客日报 · 11月12日：Python 之禅作者去世

2026-11-12 • 约 6 分钟 • 极客日报 · 阅读 次

今天的极客圈有点沉重：写下《Python 之禅》的 Tim Peters 去世了；另一边，大厂裁员传闻、AI 工具封号、刘海变小岛，新玩意和老焦虑齐飞。

一、V2EX 热议

  • 《腾讯裁员一半》（程序员 · 177 条回复）——帖子正文只有一句话「灭霸响指？」，标题本身就是全部信息。没有细节、没有来源，却冲上今日回复榜第一。短评：越是没实锤的消息，越能看出大家心里那根弦绷得有多紧。原帖
  • 《夹缝中生存的中国程序员》（程序员 · 103 条回复）——楼主写的是大龄程序员的双重夹击：国内背着房贷和全家开销，却随时可能撞上「优化线」；想靠 AI 工具翻身，又撞上封号与风控，连每月 200 美元订阅的账号都可能一夜清零。下班后还要像打游击一样折腾节点、换账号。短评：十几年经验成了成本而不是护城河，这才是最扎心的部分。原帖
  • 《一年前给小电驴装的监控，终于派上用场了，成功拍到偷头盔的全过程》（问与答 · 88 条回复）——去年头盔上的蓝牙耳机被偷，楼主一气之下给电动车装了一套自制「哨兵系统」。一年半后终于等来实战：头盔加耳机又被人顺走，他顶着寒风骑回家，花 5 小时回老家拿头盔、翻监控、报案，监控已提交给警方。短评：几百块的案子能不能追回另说，但这套 DIY 哨兵，值了。原帖

二、分享创造 · 新玩意

  • 《分享创造：AirIsland —— 把 Mac 刘海变成音乐、提醒事项和计时器的小岛》（分享创造）——把 MacBook 屏幕顶部的刘海区域变成一个轻量实时活动入口：没活动时安静收起，有活动时一眼能看到。能显示当前播放歌曲、封面和实时频谱并控制播放，接系统「提醒事项」可直接新增、完成待办，还有滚动设置时长的计时器。要求 Apple Silicon Mac、macOS 15 以上，开源免费。短评：刘海从「忍着用」变成「用起来」，这思路就赢了一半。原帖
  • 《开源了一个本地优先的 X (Twitter) 评论区与时间线净空扩展 KeepXClean》（分享创造）——刷 X 最烦的是热门推文评论区前排全是蓝标复读机、高仿钓鱼号和引流帖。KeepXClean 直接在浏览器本地内存里对 X 自身的 GraphQL 响应做同步过滤，单条判定不到 1 毫秒，零登录、不轮询接口，还能识别高仿号、堆砌标签和原生推广广告，内置 24 条词库规则与 4.5 秒撤销窗口。短评：不把数据发去远端大模型判断，本地就能净空，这才是隐私正确的打开方式。原帖
  • 《做了个开源 Skill，把个人网站折成一张能逛的 3D 地图》（分享创造）——不再是一排排链接，而是把网站折成一片纸模型大陆：应用、开源项目各住一座城，每个链接变成城里的一栋建筑，点进去就到原页面。地形由种子生成，海岸、山、河流、道路和森林都不是手画的固定背景，时间天色还会跟随本地时间变化。项目叫 site-to-map，MIT 开源。短评：个人主页做成这样，逛的不是网站，是心情。原帖

三、烧饼社区

  • 《Claude Fable 5.2 用了几天，我把能找到的评测和实测都整理了一下》（技术交流 · 414 条回复）——11 月 9 日 Anthropic 丢出 Fable 5.2，定位仍是「最难搞的技术活专用模型」。上下文 1M、最高输出 128K，输入 8 美元、输出 40 美元每百万 token，比上一代便宜两成；官方跑分全线压过 Opus 5.5，FrontierCode 2.0 达到 49.1%。但楼主的结论很冷静：能力确实又提了一截，可贵得要命，日常用并不比 Opus 5.5 香，官方自己也说大部分活先用 Opus 5.5 就行。短评：旗舰模型越来越像跑车——快是真快，日常通勤还是开家用车吧。原帖

四、海外极客圈 · Hacker News

  • 《Tim Peters has died》（Hacker News · 1119 分 · 125 条评论）——写下《Python 之禅》的 Tim Peters 去世了，享年 74 岁。Python 官方讨论区已发布讣告帖。Tim Peters 是 Python 核心开发者，「import this」里那十九条格言，几乎每个 Python 程序员都背过。短评：优美胜于丑陋，明了胜于晦涩——他留下的不只是代码，更是一种写代码的品味。原帖
  • 《My AI agents found an unmapped Maya site?》（Hacker News · 975 分 · 355 条评论）——作者用 AI 智能体发现了一处未被标注的玛雅遗址，标题末尾的问号说明结论还在求证中。355 条评论的热度，说明大家对「AI 能不能真的帮考古学家找到新遗址」这件事既兴奋又较真。短评：AI 出门「挖宝」了，是真是假，等实地验证。原帖

五、Telegram · 极客分享精选

  • 《Mister：IDM 的开源 Rust 版本》（极客分享 · 1.17K 浏览）——基于 Rust 开发的免费开源下载管理器，界面和操作方式与 IDM 近乎一比一，支持 Windows、Linux 和 macOS，也有中文。支持多连接分段下载、断点续传、下载队列和定时任务，还能用浏览器扩展接管下载、下载网页视频、BT 种子和磁力链接，甚至提供本地 API 和 MCP 接口，可以通过 AI 助手管理下载任务。短评：IDM 平替年年有，Rust 重写还带 MCP 的，不多见。原帖
  • 《Hoistbay - 一款免费开源的 Amazon S3 和 CloudFront 桌面管理工具》（极客分享 · 1.1K 浏览）——桌面端管理 S3 和 CloudFront：按文件类型自动设置 Cache-Control、Content-Type 等上传规则，一键清理 CloudFront 缓存，支持多 AWS 账户及区域快速切换。无需注册账号，密钥保存在系统钥匙串中，没有中转服务器和遥测，支持 macOS 和 Windows。短评：把云存储管得像本地文件夹，对常年和 S3 打交道的人来说很友好。原帖
今天的极客日报里，最热闹的是工具，最沉重的是人。Tim Peters 留下的十九条格言还在每个 Python 解释器里，而另一边，程序员们还在为「不被时代抛弃」每天折腾。工具会过时，品味不会。
