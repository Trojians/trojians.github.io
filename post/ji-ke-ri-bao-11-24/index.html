极客日报 · 11月24日：黄仁勋杀回来了

2026-11-24 • 约 4 分钟 • 极客日报 · 阅读 次

今天的极客圈被一个人刷屏了——黄仁勋杀回英伟达，HN 和 V2EX 同时炸锅；另外，从零手写的浏览器 Ladybird 悄悄进了 Alpha，Mac 党一年一度的软件清单也来了。

一、V2EX 热议

  • 《黄仁勋又重新回到了他的英伟达，服了，把全世界当猴耍》（V2EX 热议 · 93 回）英伟达官宣黄仁勋复任 CEO，距离他卸任仅 11 天。消息在 Hacker News 上冲到 2486 分、3419 条评论，V2EX 这帖也盖到 93 楼，有人调侃这出“以退为进”把全世界都耍了一圈。短评：皮衣又回来了，股价先替他鼓了掌。原帖
  • 《2026 年我的常用 Mac 软件分享》（V2EX 热议 · 108 回）tw93 的年度固定节目：按自己做的、产品开发、上网、效率四组，晒出今年每天在用的 24 款 Mac 软件。楼主感慨，有了 AI 之后反而常用软件变少了，只剩这 24 个。短评：一年一度的装机清单，照着抄作业就行。原帖
  • 《Apple ID 刚刚被盗刷了！》（V2EX 热议 · 52 回）楼主自认是 IT 从业者，Apple ID 开了 MFA、从没点过钓鱼邮件，今天早上 7 点却收到支付宝一笔 6399 元的付款提醒。好在绑定的支付宝做了限额，这笔没扣成；查了一圈，账号里没有新设备、没有新手机号，登录记录也正常。短评：MFA 不是万能，支付限额才是最后那道锁。原帖

二、分享创造 · 新玩意

  • 《[开源自荐] Ossia：一款体验超棒的 AI 原生乐谱制作软件》（分享创造）作者打《影之刃零》时被《心湖》迷住，想把曲子扒下来做成钢琴谱自己弹，索性写了个 AI 原生乐谱软件 Ossia，最近开源了。短评：为了一首歌写一个软件，这就是极客的浪漫。原帖
  • 《开源了一个基于 MyGo 的跨平台原生抓包工具，支持 TLS/HTTP2 指纹、Python 脚本等》（分享创造）桌面端 MITM 抓包与流量分析工具 FlowLens，起初用 Wails3 + Vue 写，后来听说 MyGo 能用 Go 写原生桌面应用，整套重构迁移了过去，就为甩掉 Webview 的内存占用；支持 TLS/HTTP2 指纹和 Python 脚本扩展。短评：抓包工具自己先“抓”住了更轻的路子。原帖
  • 《Claude Code 最佳控制面》（分享创造 · 18 回）第三方 Claude Code 控制界面 baocode，短时间内攒了 5000 用户，体积只有 20MB 左右，作者称它比市面上任何第三方 UI 都流畅丝滑，每个 token 输出都做了精致的 UI 适配。短评：好工具的标准很简单：小、快、顺手。原帖

三、NodeSeek 精选

  • 《iLatency公测，一个新的社区内Ping站，邀你共建》（NodeSeek）社区里新冒出来的 Ping 监测站 iLatency 开始公测，楼主邀大家一起来共建。短评：测速这事，人多了才准。原帖
  • 《【羊毛】免费一个月mistral pro，附带详细教程》（NodeSeek）免费领一个月 Mistral Pro 的路子，帖子里附了详细教程。短评：白嫖 Pro 的窗口期，先到先得。原帖

四、海外极客圈 · Hacker News

  • 《Ladybird is now in alpha》（Hacker News · 1768 分 / 410 评）从零手写的独立浏览器引擎 Ladybird 正式进入 Alpha 阶段。在 Chromium 一家独大的今天，一个不套壳的浏览器走到这一步，HN 上 410 条评论都在围观。短评：浏览器这条赛道，终于有人不抄作业了。原帖
  • 《GLM-5.4: Toward generalized coding with our first loop transformer》（Hacker News · 1107 分 / 360 评）智谱发布 GLM-5.4，主打通用编码能力，号称首个“循环 Transformer”（loop transformer）架构，HN 上拿了 1107 分。短评：编码模型卷架构，下一站可能是“循环”。原帖

五、Telegram · 极客分享精选

  • 《Ghost Downloader - 一款开源的全能下载器》（Telegram 极客分享 · 1.83K 浏览）开源全能下载器，支持文件下载、BT、视频解析和直播录制；装上浏览器扩展后能直接嗅探网页里的音视频资源，B 站、YouTube 还能选画质、字幕和片段，播放列表可以批量下，覆盖 Windows、macOS、Linux 和 Android。短评：一个下载器，管了全网的视频。原帖
今天的极客圈一半在看黄仁勋的皮衣，一半在给自己的工具箱添新家伙。热闹归热闹，别忘了给 Apple ID 再检查一遍支付限额。
