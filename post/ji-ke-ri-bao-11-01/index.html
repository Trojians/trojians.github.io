极客日报 · 11月1日：Linux TCP 曝 9.8 分高危漏洞

2026-11-01 • 约 5 分钟 • 极客日报 · 阅读 次

今天的极客圈，安全话题格外抢眼：Linux TCP 曝出 9.8 分的高危漏洞，ChatGPT 与 Codex 的额度传闻也让不少人坐不住了；另一边，独立开发者们照常交作业，从 NAS 播放器到 macOS 切换器，新玩意不少。

一、V2EX 热议

  • 《[送码两天] Emby/Plex/NAS 视频播放器 Vidzer v1.2.0 发布，首次支持安卓，还支持 macOS 和 Windows》（V2EX 热议 · 89 回复）：Vidzer 1.2.0 补上了安卓版，至此覆盖安卓、macOS 和 Windows 三端，基于 MPV 播放、FFmpeg 解码，支持 Emby、Jellyfin、Plex 以及 WebDAV、SMB 等多种片源；新版还加入了弹幕、字幕样式和跳过片头片尾等功能，并带一个面向语言学习的“学习模式”。一句话短评：NAS 党的播放器又多了一个三端齐全的选择。原帖
  • 《[macOS] AbcTab：让 ⌘Tab 快得能跟上你的手 [送激活码]》（V2EX 热议 · 53 回复）：这是一款轻量 macOS 应用切换器，唤出切换面板后直接敲应用名首字母就能一步跳转，重复按同一字母可在匹配应用间轮换，中文应用同样支持，敲 W 就能直达微信。作者称已完成苹果签名与公证，可直接安装使用。一句话短评：窗口一多，省下的每一次翻找都是实打实的手速。原帖
  • 《恶心了，ChatGPT 要跟 Codex 共用额度了》（V2EX 热议 · 26 回复）：楼主转述了一封邮件：OpenAI 正在小范围测试把 ChatGPT 的 Chat 与 Work 标签页合在一起的体验，让用户从想主意到让 ChatGPT 落实执行都在一处完成，同时 Codex 在桌面应用里仍会保持独立体验。帖子标题的“共用额度”引来不少讨论。一句话短评：先别急着下结论，等小范围测试的实际规则落地再看。原帖

二、分享创造 · 新玩意

  • 《做了个 MCP 工具：给 agent 一个 App Store 链接，它把包拆成可检索的证据》（分享创造 · 0 回复）：上架应用没有源码仓库，分析竞品常常要花一下午解包、翻压缩过的 JS。作者做的这套工具通过 MCP 接入常用客户端，输入 App Store 链接后，能把包拆成可检索、可引用的证据，终端里也有同一套引擎的人类入口。一句话短评：让 AI“读”竞品之前，先给它一份能查证的证据链。原帖
  • 《[开源自荐] AgentSafe：分享截图和调试日志前，在本地检查不想公开的内容》（分享创造 · 0 回复）：提 issue、晒截图时，画面里很容易顺带露出内部项目名、邮箱或域名，日志里也可能夹带认证字段和 Cookie。AgentSafe 完全在本地运行，可检查截图与日志里的敏感内容，图片还能手动框选遮盖后另存副本，原图不动。一句话短评：发帖前多一道本地检查，省下事后删帖的麻烦。原帖
  • 《搭手 1.0 发布：搜索条、可视化自动化和 AI，一个人写完了》（分享创造 · 0 回复）：作者一人写出的效率工具，支持 Windows 与 macOS，把 Alt+Space 唤出的搜索条、可视化编辑的“组合动作”和能直接操作应用的 AI 工作台放进同一个入口；免费功能不用登录，动作、笔记、待办、剪贴板等数据都存在本机。一句话短评：启动器、自动化、AI 客户端三合一，野心不小，值不值得换就看它够不够顺手。原帖

三、烧饼社区

  • 《OpenAI 新一轮融资获约 110 亿美元承诺》（烧饼社区 · 1 回复）：帖子提到，OpenAI 最新一轮融资目前获得约 110 亿美元投资承诺，不足最初 300 亿美元目标的一半，部分大型投资者兴趣冷淡，楼主顺带问了一句“什么时候泡沫破裂”。一句话短评：数字本身已经够说明问题，泡沫还是拐点，市场会比帖子先给答案。原帖
  • 《AI 能替代运维吗？》（烧饼社区 · 6 回复）：楼主抛出了一个很直接的问题：我们在 AI 和运维之间，到底扮演什么角色？帖子不长，问的却是每个运维都绕不开的事：AI 越能干，人就越要想清楚自己那一环不可替代在哪里。一句话短评：替代与否先放一边，先把“人必须在场”的环节列清楚。原帖

四、海外极客圈 · Hacker News

  • 《TCP Use-After-Free: CVE-2026-98432 / CVSS 9.8》（Hacker News · 479 分）：标题指向 Linux IPv4 TCP 的一处 Use-After-Free 漏洞，编号 CVE-2026-98432，CVSS 评分 9.8，属于最高一档的严重程度，在 HN 上拿到了 479 分、219 条评论的热度。一句话短评：评分拉满的网络栈漏洞，管服务器的朋友今天值得先看一眼。原帖
  • 《HackerTube: YouTube built from videos recommended by HN》（Hacker News · 1160 分）：顾名思义，这是一个用 HN 网友推荐过的视频拼出来的“YouTube”，以 1160 分登上当日榜首，评论也有 341 条。一句话短评：与其在算法里刷，不如直接看极客们亲手投过票的视频清单。原帖
今天的关键词是“在场”：漏洞在场要修，人也要在场——工具越强，越要清楚哪一步非你不可。
