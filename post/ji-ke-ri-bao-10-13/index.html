极客日报 · 10月13日：一句“要有光”，Codex就给游戏引擎加上了光追

2026-10-13 • 约 5 分钟 • 极客日报 · 阅读 次

今天的极客圈绕不开 AI 写代码：一边有人只说一句“要有光”，Codex 就给游戏引擎加上了光线追踪；另一边，Codex CLI 被指默认装上常驻后台进程，海外热议同样不少。

1. V2EX 热议

  • 《现在 AI 是不是逐渐能取代很多高水平程序员了》（程序员 · 82 回复）：楼主给正在开发的游戏引擎加光线追踪，只对 Codex 说了一句“要有光”，它就把光追加入 Vulkan 渲染器，一次写对并整合进现有代码。楼主正在做的引擎 EVEngine 已开源，采用 C++20 + Vulkan + WebGPU，定位类似 love2d 但功能更强。AI 对代码的理解已经不比人类差多少，这是楼主的感慨。原帖
  • 《用 Rust 重写一切，这次是 navicat》（程序员 · 59 回复）：公司收到律师函，通知全员删除 Navicat、个人版也不例外，要求改用开源的 DBeaver；楼主习惯了 Navicat 的布局和操作，索性自己用 Rust + GPUI 撸一个，全 UI 原生、无 WebView，走 ODBC 驱动，目前 MySQL、SQLite、SQL Server、PostgreSQL 都已适配。被合规推着走，反而走出一条自己造工具的路。原帖
  • 《作为一个没见过退休金的农村人，我想知道退休职工和体制内退休后退休金有多少钱？》（问与答 · 108 回复）：楼主说村里老人基本靠子女供养，只听邻居老奶奶说每月能领一百多；问了 AI 才知道退休职工每月起码三四千，比老家县城打工工资还高，小小震撼了一把，于是发帖请家里有退休职工的 V 友说说真实数字。城乡之间隔着的，有时就是这样一层信息差。原帖

2. 分享创造 · 新玩意

  • 《因为带孩子去医院，医生开的药，家里其实有，所以我开发了一个记录就诊和家庭药箱的 App》（分享创造 · 62 回复）：初衷是省下重复开药的钱：在 App 里用关键词检索，就能知道家里有没有同类药，还能记录孩子对食物和药物的反应避坑。后来楼主发现自己历年空腹血糖逐年升高，又加上健康指标追踪，用 OCR 把体检报告指标数据化，方便看数值变化。从带娃看病的小麻烦，长成了一个家庭健康档案。原帖
  • 《做了个免费的网站流量查询工具 vaneform》（分享创造）：输入任意域名，可看月访问量、流量来源、关键词和相似网站；还有收入榜、流量增长榜、AI 流量榜、外链榜可按行业筛选；同时提供 API 和 MCP，可以直接接到 Claude、Cursor 里让 AI 查数据。未登录可用大部分功能，登录后每天可查 999 次。原帖
  • 《做了个 Tibo 大神的 Codex 额度刷新雷达》（分享创造）：起因是 Codex 额度“莫名其妙今天又刷新了”，楼主在 devtools.cn 首页加了个监控，每 10 分钟追踪一次，点击可看最近的刷新记录，还附了原文出处和中文翻译。额度焦虑，硬是被做成了基础设施。原帖
  • 《分享一个监控 OpenRouter, OpenCode, NIM 等免费模型速度的网站》（分享创造）：一个给免费模型“巡逻测速”的小站，随时检测各家免费模型的速度，看看有没有值得用的。对白嫖额度党来说，快不快和能不能用一样重要。原帖

3. 烧饼社区

  • 《你们还在用 宝塔，1panl 管理面板 吗?》（linux.sb · 31 条评论）：楼主的项目跑在 Windows 上，不用统一集成环境每次要装一堆软件，而宝塔的 Windows 支持不完善、1Panel 又不支持 Windows，于是打算自己造一个管理面板，完善好了就开源。又一个“现成工具不顺手，那就自己造”的故事。原帖

4. 海外极客圈 · Hacker News

  • 《Hackers activate automatic defrosting in supermarket fridges across Europe》（Hacker News · 640 分 · 777 条评论）：据 Tom's Hardware 报道，欧洲多地超市冷柜遭到网络攻击，黑客触发了冷柜的自动除霜，门店配送和价格也受到影响。冰箱联网之后，攻击面就一路伸进了超市的冷柜区。原帖
  • 《Codex CLI installs a persistent, self-updating background daemon by default》（Hacker News · 548 分 · 272 条评论）：OpenAI 的 Codex 仓库里有人提出 issue：Codex CLI 会默认安装一个常驻、自更新的后台守护进程。和今天 V2EX 的光追帖放在一起看正合适——AI 编程工具越能干，大家就越在意它在自己机器上还做了什么。原帖
工具越能干，越要看清它在背后做了什么——今天从游戏引擎到超市冷柜，都是这句话的注脚。
