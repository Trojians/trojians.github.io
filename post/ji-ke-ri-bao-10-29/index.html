极客日报 · 10月29日：发光 LOGO 回归，触屏 Mac 遭灵魂拷问

2026-10-29 • 约 5 分钟 • 极客日报 · 阅读 次

今天的极客圈被一台笔记本抢了风头：发光的苹果 Logo 可能要回来了，而触屏 Mac 到底有没有用，吵出了 85 条回复。另一边，OpenAI 给订阅用户发了每月最高 500 美元的 API 额度，Stack Overflow 的月提问量则跌破了 1000 条。

一、V2EX 热议

  • 《兄弟们，MacBook Pro 经典 LOGO 发光的重新回归，有点小激动啊》（V2EX 热议 · 116 条回复）：新款 MacBook Pro 据说把灵动岛、触摸屏和发光 Logo 集于一身，楼主直言“特别是这个灯，逼格满满”，已经动了入手的心思。短评：Logo 会不会发光不重要，重要的是它一亮，咖啡馆里的身份感就回来了。原帖
  • 《新款 MacBook 的触摸屏真的有用吗？》（V2EX 热议 · 85 条回复）：一位多年的苹果用户发问：想触摸就得把屏幕拉近，那为什么不直接用平板？正常用键盘时屏幕又够不着，触摸屏到底用在什么场景？短评：这问题问到了点子上——触屏不是有没有，而是手离键盘那一下值不值。原帖
  • 《OpenAI 有个小福利 去领一下》（V2EX 热议 · 68 条回复）：OpenAI 宣布 ChatGPT Pro 和 Business 订阅用户每月可免费领取 API 额度，Pro 档按订阅级别每月 100 到 500 美元不等，订阅满 7 天后在账单设置里关联 API 组织即可领取，未用完不累计。短评：订阅费之外再送额度，等于变相给开发者发了张月票。原帖
  • 《现在的 AI 是不是能达到或者超越一个标准本科生了？？》（V2EX 热议 · 67 条回复）：帖子只抛了一个问题，却引来 67 条回复：现在的 AI，是不是已经达到甚至超过了一个标准本科生的水平？短评：这个问题没有标准答案，但它被反复问起本身，就说明衡量的尺子正在换。原帖

二、分享创造 · 新玩意

  • 《[送码] 做了个本地影音库 Inscura，支持电影剧集刮削和本地 AI 画面检索（Mac/Windows）》（分享创造 · 73 条回复）：Inscura 用来整理硬盘里的电影和剧集，能通过刮削补齐海报、简介和演职员信息，还支持标签与合集分类，作者这次给 V 友准备了 200 个激活码。短评：本地片库的痛点从来不是播放，而是整理，这款工具瞄得很准。原帖
  • 《写了本开源中文手册：一张 4090 从零走通 QLoRA 微调 + vLLM 部署，给不做算法的开发者》（分享创造 · 3 条回复）：作者把自己从零走一遍的过程写成了开源手册：从 QLoRA 微调、模型合并，到用 vLLM 部署成 OpenAI 兼容接口，全程只需要一张 RTX 4090，基座是 Qwen3-4B。短评：不做算法的开发者最缺的不是代码，而是“这一步到底算不算成功”的判断，这本手册补的就是这一环。原帖
  • 《从零写一个 Agent：15 章开源教程，每章都能跑》（分享创造 · 1 条回复）：开源项目 Mino 用 Go 从零写了一个终端里的 coding agent，不用任何 agent 框架，只调官方 API，15 章教程每章对应一个可运行版本，从流式问答一路写到上下文压缩和沙箱权限。短评：想搞懂 Claude Code 们内部在干什么，亲手写一个是最快的路。原帖
  • 《撸了一个 Chrome 插件：TabTerrace，打造浏览器轻量工作台》（分享创造 · 新帖）：TabTerrace 能把多个标签页合并到一个标签页里做宫格视图，最多 9 格、30 多种布局，每格都是真实网页，拖分隔线调大小、拖格子换位置，网页不会重新加载。短评：浏览器分屏只能并排两个页面时，多任务党的痛点就只能靠这种插件来补。原帖

三、烧饼社区

  • 《关于我服务器被入侵过程》（烧饼社区 · 72 条回复）：楼主复盘了自家服务器凌晨被渗透的全过程：攻击者在后台登录成功后先尝试 RCE 被拦截，随后再次上传插件拿到 Root 权限，又探测宿主机环境、写入 SSH 公钥、修改管理密码，最后测速并清理痕迹。短评：刚买的服务器还没来得及加防御就被盯上——新机器上线第一件事，永远是先关门再开张。原帖

四、海外极客圈 · Hacker News

  • 《StackOverflow now gets fewer than 1000 questions a month》（Hacker News · 353 分）：根据站内数据查询，Stack Overflow 现在每月的提问量已经跌破 1000 条。短评：当年程序员遇到问题先上 Stack Overflow，如今提问的人越来越少，答案的去向比答案本身更值得琢磨。原帖
  • 《Gemini 4 Carbon》（Hacker News · 902 分）：谷歌官方博客介绍了 Gemini 4 Carbon，帖子在 Hacker News 上拿下 902 分，成为当天最受关注的模型动态之一。短评：分数说明一切——新模型发布时，极客圈的注意力永远是最诚实的投票。原帖
发光的 Logo 回来了，提问的人却少了——极客圈的热闹，永远在新旧交替的地方。
