极客日报 · 11月26日：1Password 遭入侵，密码库没事

2026-11-26 • 约 6 分钟 • 极客日报 · 阅读 次

今天的极客圈有点魔幻：1Password 遭入侵，密码库却安然无恙；AI 帮着写代码，BUG 却越改越多；GPT-6.2 在 code golf 上赢了谷歌工程师。

一、V2EX 热议

  • 《认真问，现在是不是可以抄底了？》（投资 · 148 回复）楼主翻了历史 K 线，觉得创业板指和中证 500 都处在阶段性低位，琢磨着拿闲钱分批买这两个的宽基 ETF，不加杠杆、持有三到五年，预期总收益 20%、年化大概 5%，问这算不算一门不错的理财。帖子底下吵得挺热闹，核心分歧就一个：低位是不是底部，谁也说不准。原帖
    短评：抄底的诱惑永远在，答案永远在“不知道”里，分批和闲钱倒是两句实在话。
  • 《个人知识库怎么搞比较好？》（程序员 · 93 回复）楼主过去一直用 Word 做笔记，几台电脑换下来、系统重装几次，好多文档就这么丢了，于是发帖求教：大家都用什么工具管知识库，几年前的笔记还在吗？这问题看着小，戳中的却是每个爱折腾的人的痛点。原帖
    短评：工具年年换，笔记的命只有一条，同步和备份才是知识库的第一性原理。
  • 《我开始受 AI 毒害了。。。》（职场话题 · 51 回复）楼主负责测 APP，以前 iOS 同事“古法编程”，开发完有 BUG 当场改完；主管让他们用 AI 辅助开发之后，BUG 量直接暴涨，改完提出的 30 个 BUG，又冒出来另外 15 个，经典“改 A 出 B”。楼主气不过：有些 BUG 百分百复现，UI 正常功能却出问题。原帖
    短评：AI 写代码快是真的，但省下的时间，全交给了测试。

二、分享创造 · 新玩意

  • 《用 Rust 写了个跨平台嵌入式开发工作台 RavomIO，想替代掉笨重的 PlatformIO》（分享创造）作者被 PlatformIO 的 Python 环境和零碎工具链折腾够了，干脆用 Rust（egui + probe-rs）自己搓了一个工作台，内置 2340 多个开发板的注册表，还支持从 platformio.ini 一键迁移到 ravom.toml。嵌入式玩家可以去围观一下。原帖
    短评：嫌工具笨重就自己造一个，极客的浪漫大抵如此。
  • 《感恩节折腾项目：Linux 小主机 + 蜂窝模组，SIM 卡留家里，手机收短信、打电话（Vonode）》（分享创造 · 12 回复）家里有闲置的 Linux 小主机，装上蜂窝模组就能变成自己的短信与通话节点：SIM 卡留在家里，iPhone 或安卓上的 App 照样收发短信、打电话，当前 iOS 版已到 1.4.11。把通信掌握在自己手里，折腾党的快乐就是这么朴素。原帖
    短评：SIM 卡不出门，短信电话照常用，这才是“我的号码我做主”。
  • 《Rigdepot：把团队的 Skill、MCP、工作流统一管起来，同步到 Claude Code / Codex / OpenCode》（分享创造）团队里人人用不同的 AI 编码工具之后，问题很具体：同一个 Jira MCP 要在每个工具里按各自格式配一遍，好用的 Skill 留在某个人电脑上，靠群里传压缩包分享。Rigdepot 用 Go 写了个开源方案（0.1.0，Apache-2.0），把 Skill、MCP、工作流和 Agent 放进一个 Git 仓库统一管理，再同步到各个工具。原帖
    短评：AI 工具越多，配置越散，有人出来收拾残局总是好事。

三、NodeSeek × 烧饼社区

  • 《iLatency公测，一个新的社区内Ping站，邀你共建》（NodeSeek）NodeSeek 社区里新冒出来一个 Ping 站项目，正在公测并邀请大家一起共建。标题之外暂无更多细节，感兴趣的可以直接点进原帖看看。原帖
    短评：社区自产的小工具，胜在贴合真实需求。
  • 《1Password 确认遭黑客入侵》（烧饼社区 · 前沿快讯）11 月 25 日，知名密码管理器 1Password 发布安全公告：黑客通过一名员工的企业 GitHub 账号入侵内部系统，植入恶意代码，窃取了部分用户的姓名、邮箱、账户 ID 等信息，同时拿到了私有源代码和 CI/CD 系统的访问权限。好消息是，用户的密码保险库及其中保存的所有内容、主密码、Secret Key 均未受影响，官方表示无需修改密码；但姓名和邮箱已经泄露，接下来要格外警惕冒充 1Password 的钓鱼邮件、账户恢复请求和诈骗电话。另外，官方已把相关邮件的验证码从 6 位纯数字升级为 10 位字母与数字组合。原帖
    短评：密码库没事是万幸，但邮箱泄露后的钓鱼潮，才是真正的后手。

四、海外极客圈 · Hacker News

  • 《GPT-6.2 Astra is the first model to beat Googlers' code golf records》（Hacker News · 357 分）GPT-6.2 Astra 在 Go 代码高尔夫基准上，成为第一个击败谷歌工程师纪录的模型。Code golf 比的是用最短代码解决问题，向来是程序员炫技的竞技场，模型能在上面赢过人类纪录，多少有点里程碑的意思。原帖
    短评：模型写代码短不短不重要，重要的是它开始在“人类的游戏”里赢了。
  • 《The New York Times warns photographers not to update Photoshop over AI features》（Hacker News · 337 分）《纽约时报》提醒摄影师：先别急着更新 Photoshop，原因出在新加的 AI 功能上。AI 越来越深地嵌进创作工具，专业用户对“被 AI 改图”的警惕也在同步增长。原帖
    短评：AI 功能好不好用是一回事，摄影师想不想被 AI 替自己做决定，是另一回事。

五、Telegram · 极客分享精选

  • 《Rayburst - 一款基于 Aria2 Next 的开源跨平台下载器》（极客分享 · 24 小时内浏览量约 1.99K）Rayburst 是 Motrix Next 更名后的版本，采用 Aria2 Next 下载引擎，除了常见的文件、BT 和磁力下载，还能处理更多下载场景。昨天 16:36 发布，是频道 24 小时内最火的一条。原帖
    短评：下载器这条赛道卷了这么多年，还能冒出新名字，说明需求一直都在。
今天的极客日报就到这里：工具在变快，BUG 也在变多，密码库守住了，但钓鱼邮件正在路上。保持警惕，继续折腾。
